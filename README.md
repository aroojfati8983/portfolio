# 🚀 Personal Portfolio Website

My personal portfolio website built with **React**, **Tailwind CSS**, and **Framer Motion** to showcase my projects, skills, and journey as a web developer.

## 🔗 Live Demo

[View Portfolio](https://your-portfolio.vercel.app)

## ✨ Features

- ⚡ Fast and responsive design
- 🌓 Smooth animations with Framer Motion
- 📱 Fully mobile-friendly
- 🎨 Modern UI with Tailwind CSS
- 📂 Projects showcase with live demo & code links
- 💬 Contact section with social links

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React | Frontend framework |
| Vite | Build tool |
| Tailwind CSS | Styling |
| Framer Motion | Animations |
| React Icons | Icons |
